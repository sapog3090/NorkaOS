| Язык | Установщик | Норка Центр | Меню и Норка | Кто перевёл |
|---|---|---|---|---|
| English | есть | есть | есть | исходный текст |
| Русский | есть | есть | есть | Claude, проверено автором проекта |
| Українська | есть | есть | есть | **машинный черновик** (Claude), нужна проверка носителем |

Остальные славянские языки из плана (белорусский, чешский, словацкий, болгарский, сербский, хорватский, боснийский, словенский, македонский) пока не начаты. Сама Plasma переведена на все них силами KDE.

Где тексты: `pkgbuilds/norkaos-installer/app/ui/i18n/*.json`, `pkgbuilds/norkaos-center/app/ui/i18n/*.json`, `pkgbuilds/norkaos-shell/po/*.po`. Новый язык: скопировать `en.json` (или `.ru.po`), перевести, добавить код языка в выбор языка установщика (`index.html` и `locales` в `app.js`) и в список в `norkaos-center/app/ui/app.js`.
